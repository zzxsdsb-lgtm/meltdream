# SPILLED ✦ 亢奋 · 液体 · 梦境（v3：贴纸 + 音频版）

基于稳定版（`../spilled-shader-稳定版/`）与 v2 迭代而来的当前主版本。
**Spilled 核心流体 100% 保留**（velocity feedback / 多尺度旋转 advection / motor pump /
buffer 累积，RGBA16F），所有改动都是"外围"：循环节奏、换皮、贴纸、声音、UI。

## 自动循环（40s 周期，完全自动，与鼠标无关）

| 时间 | 阶段 |
|---|---|
| 0–1s | 平静：底图逐像素原样清晰，流体仅 10% 维持 |
| 1–3s | 突然爆发：2 秒拉满原版速度 + slam 过冲（最高 +70%） |
| 3–24s | 高速亢奋：原版全力持续，画面逐步被液体完全覆盖 |
| 24–34s | 逐渐减弱（连续，不突然停止） |
| 28–37s | 液体颜色重新凝固回底图 |
| 37–40s | 底图重新清晰 → 下一轮爆发 |

HUD 实时显示当前阶段（平静/爆发/高速亢奋/减弱/恢复）。

## 交互

| 操作 | 功能 |
|---|---|
| 点击画面 | 随机水钻贴纸出现在点击位置，被流体卷走，≈0.5s 原地渐隐 |
| 移动鼠标 | 光标处柔和紫蓝/糖果粉光晕（仅发光，不影响流体） |
| ♪ 声音胶囊 | 开/关程序生成的氛围音频（**默认开**，浏览器要求一次点击后出声） |
| 点击画面（声音开时） | 水钻落水的一记脆响，与贴纸生成同步 |
| 按住 `I` | 恢复底图（原版机制） |
| `R` | 重新泼洒（重置循环） |
| `空格` | 暂停/继续 |
| 抽屉滑杆 | 实时调节全部参数 |

## 声音（Web Audio 全程序合成，无任何素材）

- **亢奋低鸣**：双失谐锯齿 + 低通的恒定背景层（不随阶段起伏，像房间的底噪）
- **呼吸**：带通噪声 + 7s 周期 LFO 包络，亢奋时呼吸略加快
- **爆发轰鸣**：低频双击（94→36Hz 下滑正弦），爆发的"心跳"冲击
- **水钻脆响**：点击生成贴纸时的一记高频闪烁音
- 主音量在 `main.js` 的 `master.gain.value = 0.9` 处可调

## 滑杆

| 滑杆 | 默认 | 范围 | 作用 |
|---|---|---|---|
| 流动强度 | 1.30 | 0 – 4 | 1.0 = 原版速度的一半；2.0 = 原版速度；4.0 = 原版两倍 |
| 平静时长 | 1s | 0 – 10 | 每轮循环开头底图静止、清晰可见的时间 |
| 循环周期 | 40s | 20 – 120 | 平静→爆发→高速→减弱→恢复 一整轮的长度 |
| 流动速度 | 1.20x | 0.5 – 2 | 缩放平流/泵/循环节奏的全局时钟 |
| 浮雕强度 | 150 | 80 – 400 | 液面起伏深度（原作 150） |
| 高光光泽 | 1.00 | 0 – 2 | 珠光小闪强度（原作 2.5 = 1.67） |
| 霓虹辉光 | 0.70 | 0 – 2 | 光晕强度 |
| 换皮色相 | 0.15 | -π – π | 整体色相旋转（弧度） |
| 闪粉含量 | 0.60 | 0 – 1.5 | 液体中闪粉的密度与亮度 |

「恢复默认参数」一键还原。

## 实现

- **Buffer A（流体）**：原作逐字保留 + 自动循环包络（uWake/uCycle/uT2/uT3/uR0/uR1，
  只调制 act/pump 强度）+ 恢复期速度弛豫 + 闪粉浓度场（alpha 通道随流平流）。
  16F 缓冲 + 速度 0~1 钳制等价原作 8 位饱和，无量化几何形。
- **Image（着色）**：原作骨架（梯度→法线 z=150→漫反射→pow(spec,36)×2.5 高光）
  逐字保留；视觉改造 = 色相旋转（`recolor`，亮度结构 100% 保留、色相压入
  蓝紫↔糖果粉扇区）+ 随流闪粉 + 鼠标光晕 + 恢复期底图逐像素直出。
- **声音**：Web Audio 程序合成——呼吸（带通噪声+LFO）、爆发轰鸣（双击低频）、
  亢奋低鸣（双失谐锯齿+低通）、随机闪烁音；全部增益由循环包络驱动。
- **贴纸**：14 枚水钻 PNG 预载，点击时 DOM 叠层原地渐隐，并触发水钻脆响。
